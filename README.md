# Khushi Birthday — V4

Static, mobile-first birthday story for Khushi from Prem.

## Run locally

Use a local static server so relative media paths behave exactly like deployment:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080/` from the `khushi-birthday` directory.

## Deploy

Upload the contents of this folder to a GitHub repository and enable GitHub Pages. All media uses relative paths, so it also works when hosted under a repository subpath such as `/khushi-birthday/`.

## Media

- `assets/music/song.mp3` — supplied by Prem.
- `assets/photos/` — supplied relationship photos/screenshots, kept at their original pixel dimensions.
